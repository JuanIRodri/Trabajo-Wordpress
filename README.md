# Proyecto: Tienda de regalos personalizados

## Idea general
Una web donde el usuario pueda:
- Elegir un regalo (taza, remera, box, etc.)
- Personalizarlo (nombre, mensaje, imagen)
- Agregarlo al carrito
- Pagar online

Todo armado con WooCommerce.

## Estructura de la página
### 1. Inicio
- Banner (ej: "Regalos únicos y personalizados")
- Productos destacados
- Botón de compra

### 2. Tienda
- Listado de productos:
  - Tazas
  - Remeras
  - Cajas sorpresa
- Filtros simples (opcional)

### 3. Producto (IMPORTANTE)
Cada producto tiene:
- Nombre
- Precio
- Imagen
- Opciones:
  - Nombre personalizado
  - Mensaje
  - Subir imagen (opcional)

*Nota: Esto se implementa utilizando plugins de "product addons".*

### 4. Carrito
- Productos seleccionados
- Precio total

### 5. Checkout (pago)
- Datos del cliente
- Medio de pago (puede ser simulado o tipo transferencia)

### 6. Contacto
- Formulario
- Redes sociales
